# Postula

The open-source Personal ATS (Applicant Tracking System). Track your applications, manage headhunters, and compare offers in one place. Built for everyone from interns to senior engineers.

## What is Postula?
Searching for a new job or *alternance/apprentice* is chaotic. Postula is a self-hosted or cloud-ready ecosystem to manage your career moves:
* **Browser Extension:** One-click save jobs directly from LinkedIn, Indeed, and Welcome to the Jungle.
* **Smart Kanban Board:** Automatically track your pipeline from "To Apply" to "Offer".
* **Total Compensation Tracker:** Compare job offers beyond just the base salary.

## Tech Stack
* **Web:** Next.js (App Router), CSS Modules
* **Extension:** Plasmo (React)
* **Database & Auth:** Supabase
